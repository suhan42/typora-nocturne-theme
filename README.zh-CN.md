# Typora Nocturne Theme

一个受 [Kiro IDE](https://kiro.dev) 配色启发的单文件 Typora 暗色主题。

Nocturne 使用深紫灰色背景、柔和的紫色强调色、清晰的代码样式，以及针对 Markdown 阅读和写作细节优化过的排版。它适合专注写作、技术笔记、知识库整理和长时间阅读。

![thumbnail](source/preview01.png)

## 特性

- 单个 CSS 文件即可安装
- 受 Kiro IDE 启发的深紫灰色配色
- 类 GitHub 主题的宽正文阅读区域
- 从 `h1` 到 `h6` 的清晰标题层级
- 更清晰的代码块显示和光标颜色
- 优化正文、源码模式、代码块中的选中文本颜色
- 区分明显的链接、粗体、行内代码、高亮、上标和下标样式
- 更易读的表格样式，包含完整单元格边框
- 优化引用块、任务列表、分割线和侧边栏当前项状态
- 更好地支持源码模式、YAML 块、原始 HTML 块、数学块和 Mermaid 图表
- 默认使用系统字体栈，不依赖额外字体文件

## 适合场景

- Markdown 笔记
- 编程文档
- 个人知识库
- 技术写作
- 暗色模式下的长文阅读

## 安装

1. 下载 `nocturne.css`。
2. 打开 Typora。
3. 进入 `偏好设置` → `外观` → `打开主题文件夹`。
4. 将 `nocturne.css` 复制到 Typora 主题目录。
5. 重启 Typora。
6. 在主题菜单中选择 **Nocturne**。

## 字体

该主题不捆绑自定义字体，默认使用系统字体栈，以提高可移植性。

推荐的可选字体：

- 正文：系统 UI 字体、Inter、Noto Sans CJK、微软雅黑、苹方
- 标题：系统 UI 字体、Noto Serif CJK SC、思源宋体、宋体
- 代码：Cascadia Code、Fira Code、JetBrains Mono、Consolas、Menlo
